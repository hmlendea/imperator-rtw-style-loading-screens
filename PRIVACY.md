## 🔎 What This Document Covers

This document describes how Imperator: Rome - RTW-Style Loading Screens at https://github.com/hmlendea/imperator-rtw-style-loading-screens handles personal data. It covers the application behaviour and verified integrations described below. Where the software is self-hosted, the instance operator may have separate responsibilities described below.

## 🏠 Self-Hosted Deployments

This project is a mod for Imperator: Rome consisting of DDS image files. Users download and install the mod locally. The project maintainers do not operate a service, collect data from installations, or receive any data from self-hosted instances. Instance operators (players) control their local game installation and mod directory entirely.

No data is sent from a self-hosted instance to project maintainers or external services. There is no telemetry, update checks, crash reports, email, authentication, reverse-proxy, object-storage, or monitoring integrations built into the mod.

## 📥 Data We Handle

### Data Provided to the Application

No personal data is requested, collected, or stored by the mod. The mod consists solely of DDS image files that replace vanilla loading screens.

### Data Generated or Collected by the Application

No personal data is generated or collected automatically by the mod. The mod does not execute code, log events, or transmit data.

### Data Received from Integrations

No personal data is received from integrations or third parties. The mod has no integrations.

## 🧭 Processing and Use

The application processes no personal data. The mod functions by providing replacement DDS image files that the game loads instead of the vanilla loading screens. No data processing occurs.

## 🗄️ Storage, Retention, and Deletion

No personal data is stored by the mod. The mod files (DDS images) are stored in the user's local game mod directory. The user controls installation, updates, and removal of the mod files. The project maintainers do not store any user data.

## 🔗 External Processing and Integrations

The application has no built-in external data transfer. The mod does not connect to any external services, APIs, or integrations.

## 🛡️ Data Protection and Security

The mod consists of static DDS image files. No personal data is processed, transmitted, or stored. The original maintainers are not responsible for changes, modifications, or privacy issues introduced by downstream forks.
