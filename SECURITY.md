# Security Policy

This project is a mod for Imperator: Rome consisting solely of DDS image files that replace vanilla loading screens. It contains no executable code, runtime, network communication, or data processing. This policy covers vulnerability reporting for the mod assets and distribution channels maintained by the original authors.

## 🚨 Reporting a Vulnerability

Please do not disclose suspected vulnerabilities publicly before maintainers have had an opportunity to validate and remediate them.

To report a vulnerability:
- [GitHub Security Advisories](https://github.com/hmlendea/imperator-rtw-style-loading-screens/security/advisories)
- Contact the maintainers directly via GitHub issues

## 📌 Scope

The original maintainers are not responsible for changes, modifications, or security issues introduced by downstream forks.

The subsequent report categories are in scope for this repository:
- Malicious or corrupted DDS files distributed through official channels
- Supply-chain compromise of official distribution channels (Steam Workshop, Nexus Mods, GitHub Releases)

The subsequent categories are out of scope unless explicitly stated to the contrary:
- Issues in the base game Imperator: Rome
- Issues in mod loaders or third-party tools
- Modified or repackaged versions distributed by third parties
- Social engineering or phishing unrelated to official distribution channels

## 📢 Disclosure Policy

This project follows coordinated disclosure:
1. Vulnerabilities are investigated privately.
2. A remediation plan is prepared and validated.
3. Public disclosure is published after a fix, mitigation, or agreed risk decision is available.
4. Credit is attributed in accordance with reporter preference and project policy.
